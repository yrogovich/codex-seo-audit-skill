# Search, analytics, competitors, and authority

Use existing authorized connections or user-provided exports. Do not request passwords, print credentials, assume a paid data service, or purchase reports. Work with public evidence while optional access is pending.

## Search Console and analytics

Confirm property, hostname, protocol, timezone, dataset dates, filters, row limits and aggregation. Prefer comparable complete periods (for example 28 days versus previous 28 days, with a year-over-year view where useful). Account for seasonality, device/country mix, brand/nonbrand intent and tracking changes. Label partial days and sparse data.

Inspect important landing pages and queries for clicks, impressions, CTR and position with their denominators and segmentation. Do not average averages blindly; aggregate CTR as clicks/impressions. Query datasets may omit anonymized rows and do not necessarily reconcile to page totals. Do not attribute CTR decline to titles without checking position and query mix.

Use inspection/indexing data to distinguish declared and Google-selected canonicals and actual indexed status; retain inspection timestamps and property scope. A live eligibility test is not an indexed-state observation. A `site:` query is not a reliable index count.

Connect organic landing traffic to defined conversions where tracking supports it. Distinguish users, sessions, events and key events; do not reconcile platforms as if attribution models were identical. Treat tracking failures as measurement problems. Traffic changes coincident with algorithm updates are hypotheses; consult official update history and check releases, seasonality and demand before causal claims.

## Keyword and competitor analysis

Select a small set of commercially meaningful themes from real page intents. Inspect current results in the target language and location using available search tools. Record query, engine, locale, date and device where known. Name actual competing URLs and page types; business competitors and search competitors can differ.

Map intents to existing URLs, identify substantive coverage gaps and overlap, and distinguish suggested themes from measured keyword demand. Only report search volume, difficulty, rankings or market share when the data source provides them, with geography, period and methodology. Do not manufacture numbers from qualitative judgment or call a personalized search a rank tracker.

## Backlinks and reputation

Analyze authorized backlink exports/services with index date, coverage, deduplication and sample limits. Inspect referring-domain relevance, destination status, lost links to moved pages, anchor patterns and credible mentions. Domain authority and spam/toxicity metrics are provider heuristics, not Google scores or proof of a penalty. Do not recommend bulk disavowal, link buying, or automated outreach. Without backlink data, report that profile completeness cannot be assessed; a few public mentions are not a full profile.

## Repeat audits

Keep baseline and current evidence immutable. Align canonical URL mapping, template samples, device, tool, period, filters and thresholds. Identify coverage changes separately from improvements. For each prior finding record resolved/persistent/new/unverified with current evidence. A missing measurement is not resolution. Retest implementations immediately; monitor search outcomes over an explicitly chosen later period without promising a fixed ranking-recovery time.
